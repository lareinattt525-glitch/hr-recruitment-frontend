# HR招聘系统 · 前端

真正调用后端API的网页应用（不是假数据演示）。基于 Vite + React + Tailwind CSS，构建后是纯静态文件，可以部署到任何静态网站托管服务（Vercel / Netlify 都可以，推荐 Vercel）。

## 本地预览

```bash
npm install
npm run dev
```

打开终端提示的地址（通常是 `http://localhost:5173`），第一次会看到登录页，需要先填一个能访问到的后端地址。

## 部署

```bash
npm run build
```

会在 `dist/` 目录生成纯静态文件，把这个目录部署到 Vercel/Netlify 即可（Vercel 会自动识别是 Vite 项目，直接用默认设置构建就行，构建命令 `npm run build`，输出目录 `dist`）。

## 使用说明

- 打开网页后先填后端地址（部署到 Railway 后拿到的那个 `https://xxx.up.railway.app` 形式的地址）
- 第一次使用选"首次创建管理员"，需要用到部署后端时设置的 `ADMIN_SETUP_KEY`
- 之后用管理员账号登录，去后端用 `POST /users` 接口创建HR、用人部门、业务面试官的账号（前端暂时没做账号管理页面，这一步还是要用命令行或 Postman/reqbin 这类工具调接口，见后端README）
- 各角色登录后只会看到自己权限范围内的功能，后端会做真实的权限拦截

## 和之前"网页原型"的区别

之前给你看的那个可以自由切换角色、点一下就能看效果的版本，用的是假数据、直接调用AI，跟后端没关系，是产品演示用的。这一版是真的连后端数据库，操作会真实落库，需要登录，权限也是真实生效的。
